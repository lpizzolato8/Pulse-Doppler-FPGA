# Fixed-Point Specification

This document is the contract between the MATLAB golden model (`matlab/model/`) and the
RTL (`rtl/`). Every stage is defined down to the bit, so the testbenches can require
**exact** equality with the model's vectors.

## Notation
- `rsr(x, s)` — round-half-up right shift: `floor((x + 2^(s-1)) / 2^s)`. In RTL: add
  `1 << (s-1)` then arithmetic shift right.
- `sat(x, w)` — saturate to the signed `w`-bit range `[-2^(w-1), 2^(w-1)-1]`.
- `round()` — MATLAB `round` (half away from zero). Used only when building ROMs.
- Complex values are `{I, Q}` pairs of two's-complement integers.
- `P` — global pulse index counted from reset. `n` — fast-time sample index within the
  PRI (`0..N_FAST-1`, `N_FAST = 288`). `r` — range bin (`0..255`). `d` — Doppler bin.

## ROMs (generated by `matlab/model/gen_luts.m`)
| ROM | Entries | Format | Definition |
|---|---|---|---|
| `chirp` | 32 | 12b I, 12b Q | `round(2047·exp(jπ(B/τ·t² − B·t)))`, `t = n/fs` |
| `mf_coef` | 64 | 12b I, 12b Q | `0..31`: matched, `h[k] = conj(chirp[31−k])`. `32..63`: Taylor-weighted, `round(2047·w[31−k]·conj(chirp_f[31−k]))`, `w` = Taylor (n̄ = 4, −35 dB), peak 1 |
| `sincos` | 1024 | 12b cos, 12b sin | `round(2047·{cos,sin}(2πk/1024))` |
| `clutter` | 288 | 12b I, 12b Q | Fixed-seed random reflectivity (exp. decay over bins 0..95) ⊛ chirp, peak component 1500 |
| `window` | 64 | 16b unsigned | `round(65535·(0.42 − 0.5·cos(2πp/63) + 0.08·cos(4πp/63)))` (Blackman) |
| `tw64`, `tw16` | 64, 16 | 16b signed | `round(2^14·cos(2πe/L))`, `round(−2^14·sin(2πe/L))` |
| `log_lut` | 32 | 4b unsigned | `round(10·log2(1 + i/32))` |

## 1. Target emulator → 12-bit I/Q, one sample per 10 clocks
Per target `t` (enable `en`, range bin `r_t`, Doppler step `dphi_t` (16b), amplitude `a_t` (8b)):
1. Doppler phase `φ = (P·dphi_t) mod 2^16`. The accumulator is 0 at reset and adds
   `dphi_t` at the start of every PRI after the first.
2. `k = φ >> 6`; `c = sincos.cos[k]`, `s = sincos.sin[k]`.
3. Scaled phasor: `pI = (a_t·c) >>> 8`, `pQ = (a_t·s) >>> 8` (floor).
4. If `en` and `r_t ≤ n < r_t + 32`, with `m = n − r_t` and `(cI, cQ) = chirp[m]`:
   - `eI = (cI·pI − cQ·pQ) >>> 11`
   - `eQ = (cI·pQ + cQ·pI) >>> 11`

   (floor). Otherwise the target contributes 0.

Clutter: when `clutter_en`, add `clutter[n]`. It is identical every PRI, so it sits at zero Doppler.

Noise: one xorshift32 state `x` (seed `0xACE12468`) is used for each sample, then advanced
(`x ^= x<<13; x ^= x>>17; x ^= x<<5`). It advances every sample even when noise is
disabled.
- `nI = Σ nibbles[3:0] of x − 30`
- `nQ = Σ nibbles[7:4] of x − 30`

This is approximately Gaussian with σ ≈ 9.2 LSB. When `noise_en`, add `(nI, nQ) << noise_shift`.

Output: `sat(Σ, 12)` per component.

## 2. Pulse compression → 16-bit I/Q, 256 outputs per PRI
The delay line is cleared at the start of each PRI, so `x[n<0] = 0`. `h` is the matched set
(`pc_taper = 0`) or the Taylor-weighted set (`pc_taper = 1`) of `mf_coef`. Taylor weighting
lowers the peak range sidelobe from −14 dB to −26 dB (the floor for BT = 16) for 0.9 dB of
SNR loss.
- `y[n] = Σ_{k=0..31} h[k]·x[n−k]` (exact complex integer arithmetic)
- `pc[r] = sat(rsr(y[r+31], 12), 16)` for `r = 0..255`

## 3. MTI two-pulse canceller (bypassable)
`mti_P[r] = sat(pc_P[r] − pc_{P−1}[r], 16)`, with `pc_{−1} = 0`. The delay line updates
every PRI whether or not MTI is enabled. With MTI off, `mti = pc`.

## 4. Corner turn + slow-time window
CPI `c` covers pulses `64c .. 64c+63` (`p = P mod 64`). Read order: for `r = 0..255`, for `p = 0..63`.
The window is Blackman (−58 dB sidelobes). Hamming's −43 dB far sidelobes are not enough:
inside the MTI notch the noise floor drops, and a strong target's Doppler sidelobes there
would be detected.
- Window on: `v = rsr(mti·w[p], 16)`. This always fits in 16 bits.
- Window off: `v = mti`.

## 5. 64-point radix-2² DIF FFT (unscaled)
The array is processed in place in input order, with `L = 64, 16, 4` and blocks of length `L`:
1. **BF2I**: for `n < L/2`: `(a, b) ← (a + b, a − b)` on `(x[n], x[n+L/2])`.
2. **BF2II**: for each half `h ∈ {0,1}` and `n < L/4`, on `(x[hL/2+n], x[hL/2+n+L/4])`: if
   `h = 1`, first replace `b` with `−j·b = (bQ, −bI)`; then `(a, b) ← (a + b, a − b)`.
3. **Twiddle** (only for `L > 4`): element at local index `q·L/4 + n3` is multiplied by
   `W_L^e`, where `e = n3·bitrev2(q)`, and skipped when `e = 0`:
   - `I' = rsr(I·c − Q·s, 14)`
   - `Q' = rsr(I·s + Q·c, 14)`

Output position `p` holds `X[bitrev6(p)]`. The **shifted Doppler bin** is
`d = (bitrev6(p) + 32) mod 64`, so `d = 32` is zero velocity.

Widths needed (bounded by `|X| ≤ 64·√2·2^15`):

| Point | 16 → BF2I | → BF2II | → TW | → BF2I | → BF2II | → TW | → BF2I | → BF2II |
|---|---|---|---|---|---|---|---|---|
| Width | 17 | 18 | 19 | 20 | 21 | 21 | 22 | **23** |

## 6. Magnitude and log
- `mag = max(|I|,|Q|) + (3·min(|I|,|Q|) >> 3)`. This is at most 23 bits, unsigned.
- For `mag = 0`: `L = 0`.
- Otherwise:
  - `e` = index of the leading one
  - `f = (mag·32 >> e) − 32` (5 bits below the leading one)
  - `L = 10·e + log_lut[f]`

`L` ranges over 0..230 at 0.602 dB/LSB, and is stored at RD-map address `d·256 + r`.

## 7. CA-CFAR (log domain, along range, per Doppler row)
Settings: guard `G = 2`, training `T = 16` per side, threshold offset `off` (8 bits, LSB).
- Lead cells: `r−G−T .. r−G−1`. Lag cells: `r+G+1 .. r+G+T`.
- Both windows in range: `S = Σlead + Σlag`, `sh = 5`.
- Only one window in range: `S` = that window's sum, `sh = 4`.
- Detect when `(L_cut << sh) > S + (off << sh)`.

## 8. Peaks (3×3 local maxima)
A detection at `(d, r)` is a **peak** if its `L` is
- `>` the 4 earlier neighbours: `(d−1, r−1..r+1)` and `(d, r−1)`, and
- `≥` the 4 later neighbours: `(d+1, r−1..r+1)` and `(d, r+1)`.

Doppler wraps around (`d ± 1 mod 64`). Cells outside `r = 0..255` count as `L = 0`. The
asymmetry keeps exactly one cell of an equal pair.

Scan order is `d = 0..63`, then `r = 0..255` inside each row. A CPI reports:
- the detection count and the peak count
- the first 32 peaks as `{r[7:0], d[5:0], L[7:0]}`
- the strongest peak (largest `L`, first in scan order on a tie)

## Vector files (`sim/vectors/<scenario>/`, one hex word per line)
| File | Word | Order |
|---|---|---|
| `cfg.hex` | one field per line | see `matlab/model/write_cfg.m` |
| `emu.hex` | `{I12, Q12}` | time order, `N_FAST` per pulse |
| `pc.hex`, `mti.hex` | `{I16, Q16}` | per pulse, `r = 0..255` |
| `win.hex` | `{I16, Q16}` | per CPI, `r` outer, `p` inner |
| `fft.hex` | `{I23, Q23}` | per CPI, `r` outer, output position `p` inner |
| `map.hex` | `{peak, det, L8}` (10b) | per CPI, address `d·256 + r` |
| `det.hex` | detection count (16b), peak count (16b), then 32 × `{r,d,L}` peaks (22b, 0 if unused) | per CPI |

`cfg.hex` fields: for each target `en, range, dphi, amp`; then `clutter_en, noise_en,
noise_shift, mti_en, win_en, cfar_off, n_cpi, pc_taper`.
